## About

AgentoGPT is a no-code platform for building custom AI chatbots and agents trained on your own content. You feed an agent your sources — uploaded files (PDF, DOCX, TXT, MD, HTML, CSV, JSON, XML), pasted text, web pages by URL, or a full sitemap crawl — and it answers questions from that material.

The platform is built around strict grounding: an agent answers only from the sources you provide, and when the answer isn't there it politely declines — "I'm sorry, I don't have that information yet." — instead of making something up. Retrieval uses BM25 with typo tolerance, so a visitor's misspelling still finds the right passage. Agents can be deployed on your website with a one-script-tag embed widget, shared through a public link, or connected through the REST API.

## Features

- Custom AI agents ("projects") trained on your own files, text, URLs and sitemaps
- Strict source-only answering — the agent declines when the answer is not in its sources
- Embed widget for any website (one script tag), public share pages, and an in-dashboard chat
- REST API v1 with scoped API keys, plus a per-agent MCP endpoint
- Actions: 16 built-in tools, calls to your own external APIs, and MCP connectors
- Scheduled tasks, team roles (Owner / Admin / Editor / Viewer), and per-agent analytics
- Per-agent personalisation: logo, chat colours, light/dark chat theme
